CUSTOMIZE BEFORE PUBLISHING
1. Replace Dille/profile text as desired.
2. In contact.html, replace YOUR_EMAIL@example.com, YOUR_USERNAME, and YOUR_PROFILE.
3. Create a Formspree form and replace YOUR_FORM_ID in the form action.
4. In projects.html, replace sample GitHub links with links to your actual repositories.
5. Update skills/progress values so they honestly reflect your current experience.

LOCAL PREVIEW
Open index.html in a browser. Keep all files in the same folder.

GITHUB PAGES
1. Create a GitHub repository (for example, my-portfolio).
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the deployment and open the Pages URL shown in Settings > Pages.

This is a static site; no server or build step is required.
